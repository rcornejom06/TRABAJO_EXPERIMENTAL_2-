# Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto!

Por favor sigue estos lineamientos para asegurar una colaboración ordenada.

## Requisitos Previos

- Instala Python 3.x y pip.
- Instala Docker (opcional, pero recomendado).
- Clona el repositorio y crea un entorno virtual:  
  ```bash
  python -m venv venv
  source venv/bin/activate  # En Linux/Mac
  venv\Scripts\activate     # En Windows
  pip install -r requirements.txt
  ```

## Cómo contribuir

1. **Haz un Fork del repositorio.**
2. **Crea una rama** para tu cambio:
   ```bash
   git checkout -b mi-feature
   ```
3. **Realiza tus cambios** siguiendo el estilo del proyecto.
4. **Asegúrate de que las pruebas pasen** antes de enviar tu contribución.
5. **Haz un Pull Request** explicando claramente el cambio y por qué es necesario.

## Buenas Prácticas

- Sigue la estructura y convenciones del código existente.
- Escribe comentarios claros y útiles.
- Si agregas una nueva app o módulo, incluye documentación básica.
- Actualiza el README.md si tu cambio afecta la forma de usar el proyecto.

## Reportar errores

Puedes reportar errores mediante la pestaña de [Issues](https://github.com/rcornejom06/TRABAJO_EXPERIMENTAL_2-/issues). Por favor incluye:

- Descripción clara del error.
- Pasos para reproducirlo.
- Sistema operativo y versión de Python.

## Contacto

Si tienes dudas, puedes contactarme por GitHub o abrir un Issue.
